# 🌌 K 巨星距离估计器 (K-Giant Distance Predictor)

基于 LAMOST 巡天数据与机器学习算法SVR(支持向量回归）的 K 型巨星距离预测工具。本项目利用恒星大气参数（logg,teff，feh)和测光数据（g_r)构建回归模型，实现对K巨星距离模数及物理距离的精准估计。

---

## 📋 项目简介

准确测定恒星距离是研究银河系结构的基础。K 型巨星作为重要的“标准烛光”，其距离测量对于描绘银河系晕和盘的三维结构至关重要。

本项目提供了一个端到端的科研级数据分析解决方案：
- **数据清洗与物理筛选**：自动化解析 LAMOST 原始光谱数据，基于物理约束严格筛选高纯度 K 巨星样本。
- **机器学习建模**：使用支持向量回归 (SVR) 算法构建非线性回归模型，预测K巨星的距离模数。
- **多维可视化分析**：提供赫罗图、残差分析、误差分布及距离空间分布等多维度可视化结果。

## 🛠️ 快速开始指南

### 1. 环境准备
确保您已安装 Python 3.8+，本项目已打包为标准的 Python 库，支持通过 `pip` 进行本地安装。请确保你的环境中已安装 `numpy`, `pandas`, `scikit-learn` 等基础库。

### 2. 安装包 (两种方式)

#### 1. 直接安装（用户模式）
如果你只是想使用这个包进行预测，不需要修改源码，请在项目根目录下运行：
```bash
pip install .
```
#### 2. 普通安装（用户模式）
如果你需要调试代码或修改逻辑，建议使用可编辑模式。这样修改代码后无需重新安装即可生效：
```bash
pip install -e .
```
### 3.数据准备
将 LAMOST 原始数据文件（.txt 格式）放入项目目录，命名为 ajacc9bbt1_mrt.txt (或修改 CSV.py 中的文件名)，请确包含teff，logg，g_r，feh及其相对误差如e_logg等列名。
运行转换脚本：
```bash
python CSV.py
```
### 4.运行预测
执行测试脚本以启动训练和评估流程：
```bash
python test.py
```
## 📂 项目文件使用指南

除了核心的 Python 包，项目中还包含以下文件，供开发者或高级用户使用：

- **`test.py`**
    - **用途**：这是项目的主测试脚本。
    - **如何使用**：在命令行中运行 `python test.py`。它会自动执行完整的数据处理、模型训练、评估和绘图流程，并生成上述所有结果图。

- **`CSV.py`**
    - **用途**：这是一个数据预处理工具。
    - **如何使用**：如果你的原始数据格式与本项目的要求不符，可以修改此脚本中的逻辑，用于将你自己的数据转换为标准的 CSV 格式。

- **`ajacc9bbt1_mrt.txt`**
    - **用途**：这是本项目使用的原始数据文件，格式为 LAMOST 的 MRT (Machine-Readable Table) 格式。
    - **如何使用**：`CSV.py` 脚本会读取此文件，并将其解析、清洗后转换为 `test.py` 所需的 `data.csv` 格式。当然用户可以自己到导入，该文件只提供一个案例。

- **`pyproject.toml` / `setup.py`**
    - **用途**：这是项目的打包配置文件。
    - **如何使用**：普通用户无需操作。

## 🛡️ 结果可靠性说明

本项目的结果具有较高的可靠性，主要基于以下几点：

- **物理约束严格**：我们在数据预处理阶段引入了严格的K巨星大气参数和测光数据的数值范围，用来筛选巨星样本，从源头上保证了作为“标准烛光”的有效性。

- **误差控制良好**：最终模型的 RMSE 为 0.4430mag，R² 为 73.67％，误差分布呈正态且无偏，证明了 SVR 算法在处理此类非线性问题上的有效性。

## 📝 总结与展望

本项目成功构建了一个基于 SVR 算法的 K 巨星距离估计模型。通过严格的数据清洗与物理筛选，模型在测试集上表现出了良好的鲁棒性与预测精度（RMSE ≈ 0.4430 mag）。该工具能够有效辅助天文研究人员快速处理 LAMOST 巡天数据，为银河系三维结构的研究提供数据支持。
